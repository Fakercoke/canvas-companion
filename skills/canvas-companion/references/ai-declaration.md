# Write an accurate AI-use declaration

Use when an assignment requires acknowledgement or the user requests a declaration. An acknowledgement does not make a prohibited use permissible.

## Find the actual requirements

Read the assignment/course rule and any linked applicable institutional instructions that are accessible. Extract required tool/model/date fields, mandated wording/template, prompt-log/appendix requirements, placement and word-count treatment. Follow a mandated template; do not replace it with a generic statement. If policy is unavailable, label the draft provisional and say what must be checked. Do not invent a model/version when the host does not disclose it.

## Reconstruct actual assistance

Keep a concise log during substantive work in the private task workspace, or reconstruct it from the visible task history. Record actual tool, known model, date if required, task performed, whether its output remains in the final work, and what the student actually verified. Relevant activities include reading comparison, brainstorming, outlining, drafting, translation, grammar/style revision, citation checking and critique. Do not store credentials or duplicate private course documents in the log. No background monitoring is implied.

Do not assume grammar-only use when drafting/translation occurred. Do not infer that the student read sources, checked references or rewrote paragraphs without evidence. If prior AI use outside the visible history is unknown, ask one focused question about those uses while completing other work. Missing information is not “none”.

## Draft proportionately

Use only applicable clauses, replacing every bracketed field before finalizing. If a required fact cannot be established, flag it rather than silently supplying one.

English fallback, only if no mandatory template applies:

“I used [tool and known model, date if required] to assist with [actual activities]. [Describe how AI-generated material was used in the final work, where relevant]. [Describe only the review, changes or verification I actually carried out].”

Chinese explanation:

“我使用了[工具及已知模型]协助[实际用途]。最终文本中[实际保留或修改的 AI 辅助内容]。我本人完成了[确实进行的审核、修改或核验]。”

These are structures, not statements to paste with unsupported claims. If drafting remains, say so plainly without exaggerating its extent. If the user requests a misleading narrower description, explain the discrepancy and offer concise accurate wording.

## Check against both policy and work

Check that the statement covers material actual uses, follows required fields/placement, has no unfilled placeholders, and does not claim checks the student did not perform. Return the declaration and, when useful, a short Chinese explanation. Do not promise that a declaration guarantees academic-integrity clearance or predicts an AI-detector score. Use the current host's rules for personal attestations at submission.
