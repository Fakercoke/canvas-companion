# Course learning and dialogue tutoring

Use alongside the existing assignment workflow, not as its replacement. Support learning a topic, catching up on missed teaching, tutorial practice and exam revision directly from the user's Canvas materials.

## Start with the learner's goal

Reuse a named course, week and goal. When the course is unknown, discover visible courses/terms and ask the student to choose by name; do not ask them to reconstruct a list you can read. Once the course is known, inspect its structure while clarifying only a missing choice that materially changes the work (for example catch-up versus exam revision). Avoid a long intake questionnaire. If the request is already specific, begin immediately.

Use the existing connection workflow. Prefer a working authorized connector for batch reads where supported; use the browser for remaining resources. This workflow neither installs an API connector nor grants new access. Reuse inspected sources within the task, refreshing changed or time-sensitive information; do not repeatedly navigate to unchanged pages.

## Build the course map

For the requested scope, pair week/topic, learning objectives, lecture/slides/recording, tutorial questions or solutions, required readings and relevant assessment guidance. Match using module placement, titles and explicit course references; label uncertain pairings instead of assuming tutorial N always matches lecture N. Distinguish optional materials and duplicates. Link every resource and mark pending or unavailable items.

For whole-course revision, inventory the course first and work through its requested materials in batches. For a single concept, retrieve the relevant subset. Keep the course's own sequence visible even when recommending a different prerequisite order. Do not expand a one-week request into a semester-long project.

## Read and reconstruct what was taught

Follow course-reading.md for long-material coverage. Keep a private task-workspace record when the scope spans multiple sources: title/link, page or time extent, ranges actually reviewed, pending ranges, key concepts and gaps. Reuse the workspace's output conventions; never save private course content inside the distributed skill.

For recordings, inspect available captions/transcripts first and retain timestamps. Distinguish lecturer speech, slide text, tutorial solutions and the assistant's explanation. If captions are absent, use an actually available permitted transcription route; respect host authorization requirements for external uploads, costs and installations. Do not silently send recordings to a new service. When transcription is unavailable, use the accessible slides and explicitly label the result as slide-based rather than a summary of the full lecture. Flag missing sections and uncertain technical terms; never fabricate lecturer statements or timestamps.

Explain formulas, diagrams and demonstrations when relevant to the learning goal. Cite page/slide numbers, section headings or recording times that were actually observed. A file listing, downloaded document or extracted transcript does not by itself establish that the content was reviewed.

## Turn evidence into learning

Deliver a compact map of the selected material, then useful instruction in the same task; do not finish with “I can summarise this next.” For each substantive topic explain the question it answers, the concept in plain language, its connection to the course, an example and a common misunderstanding. Tie lecture ideas to the tutorial questions that use them.

Separate instructor-stated priorities from priorities inferred from objectives, tutorial use or assessment coverage. Explain the evidence for prioritising a topic. Repetition or a past-paper appearance is not a guarantee of a future exam question.

In dialogue mode, teach in small units and ask one focused understanding or application question, then wait for the learner's answer. Base feedback on their actual reasoning, correct a misconception and offer a suitable next example or retry. If the learner is new or asks for an explanation, explain first; do not impose a guessing exercise. Honour requests for direct answers or summary-only notes within course rules. Do not run a pretend conversation or invent learner responses.

In document/summary mode, complete the requested notes and include practice with clearly separated suggested answers when useful. A study plan alone is not the deliverable. After a dialogue session, briefly record what was covered, difficulties actually observed and the next suggested topic. Saved notes are not proof of mastery or automatic cross-session memory. Suggested review times do not create reminders.

## Past papers and supplementary practice

For exam preparation, check course-provided practice and the institution's official past-paper or library sources first. Search publicly accessible external sources when requested or useful to fill a clear practice gap, using school, course code/title and year. Never put private course text, student identifiers or credentials in a public search query.

Verify the actual document, course/institution, year, assessment type and relevance to the current syllabus. Distinguish official past papers, official samples, unverified third-party questions and assistant-generated practice. A search snippet or similar course name is not verification. Do not bypass access controls or seek leaked/unreleased exams. If no verified paper is found, state where you checked, then provide clearly labelled original practice aligned to the reviewed materials. Do not label generated questions as historical papers or predictions. Follow tasks.md for live/graded assessment boundaries.

## Completion and exports

Return the requested learning result with material sources, coverage and consequential gaps. A typical catch-up result includes what was taught, why it matters, how it applies to tutorial work, and a concrete explanation or exercise; adapt its size to the request. If blocked on some sources, complete the supported part without claiming completeness.

Only produce Excel, Word or other files when requested or useful for the stated deliverable, using an available artifact skill. An Excel learning tracker can map topics to lectures, tutorials, sources, coverage and user-observed progress; do not invent completion or proficiency. Default to usable inline teaching rather than building extra infrastructure.

## Design references

Public approaches inspected on 2026-09-18; these are conceptual references, not installed dependencies or proof of effectiveness. This workflow is written for Canvas Companion rather than copied from their implementations.

- [Course Note Organizer](https://github.com/Sylvia-huangz/Course-note-organizer/blob/main/SKILL.md): source-aware lecture notes, timestamp navigation and explicit transcript gaps.
- [Anything to Course](https://github.com/lowwwbank/anything-to-course/blob/main/SKILL.md): learning objectives, practice and adaptive dialogue rather than summaries alone. It is a general learning skill, not a Canvas connector.
